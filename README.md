# Hangman Word Guessing Game

A terminal-based Hangman game written in Python.

## Features

- Random words loaded from an English word list
- ASCII gallows that updates after wrong guesses
- Six incorrect attempts allowed
- Duplicate guesses do not remove attempts
- Input validation for letters only
- Win, loss, and replay messages

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python hangman.py
